fix: address 6 critical bugs found in ii-him audit

GlobalFocusGrab.qml - array mutations now trigger bindings
Replaced .push()/.splice() (silent mutations on list<var>) with
array reassignment so QML change signals fire properly.

Emojis.qml - critical variable and property bugs
Fixed entries to root.list, added missing sloppySearch/scoreThreshold
properties, added Component.onCompleted { load() }.

Search.qml - missing emojiToggle IPC handler
Added function emojiToggle() to Search's IpcHandler so SUPER+. works.

keybinds.lua - duplicate bindings no longer shadow Quickshell
7 keybind pairs had GS + shell fallback with the same keystroke -
second binding always overwrote first. Combined into single binding
with IPC route || fallback. Affected: SUPER+V, SUPER+., SUPER+SHIFT+S,
SUPER+SHIFT+A, SUPER+SHIFT+X, SUPER+SHIFT+R, SUPER+ALT+R, CTRL+Print.

keybinds.lua - SUPER tap-vs-hold interrupt now fires
Added with_interrupt() wrapper that dispatches the interrupt before the
target GlobalShortcut on every SUPER+key binding.

keybinds.lua + init.lua - nil-safety guards
zoomfunction defaults cursor:zoom_factor to 1.0 if config missing.
workspace_in_group defaults workspaceGroupSize to 10 if nil.

SearchWidget.qml - debounce and animation fixes
Debounce timer now slices results and calls focusFirstItem().
SearchHeightBehavior activates for both searchOpen and overviewOpen.
